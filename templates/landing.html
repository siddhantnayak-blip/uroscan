How it works

📷 Phone photo→ 🔍 Quality check→ 🎨 AI colour match (KNN)→ 🗄️ MySQL (1 transaction)→ 📈 Dashboard & trends
🎨

Colour matching

Each pad is white-balanced, converted to CIELAB and matched to the chart with a K-nearest-neighbour search using the CIEDE2000 colour distance. You get the level, an approximate value and a confidence score.

🗄️

Healthcare database

A normalised (BCNF) MySQL design with triggers that flag abnormal values, views, a stored procedure, indexes and ACID transactions, so a report is never half-saved.

🤖

AI explanations

An LLM explains results in plain English, predicts trends and answers questions about your own history. Only test values are sent, never your name.

🔐

Secure accounts

Hashed passwords, lockout after repeated failed logins, password reset, CSRF protection and role-based access for patients, lab technicians, clinicians and admins.

📈

Trends that matter

Charts for every test with the normal range shaded, alerts when a value keeps rising or stays abnormal for 3 scans in a row.

🩺

Doctor review

Clinicians see patients sorted by risk, review reports and add notes that patients can read on their dashboard.
